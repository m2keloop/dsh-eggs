# Epic 页面状态实验

这是一个尚未发布的只读排障扩展，只用于用户主动检查当前 Epic 页面是否显示登录标记、领取按钮、已在库标记和安全验证。它不登录、不领取、不连接本地程序、不发送网络请求，也不读取 Cookie、表单输入或账号详情。匹配按钮时会在页面内读取 Epic 商品侧栏按钮文字，但只在弹窗显示固定状态，不返回原始文字。

## 权限与范围

扩展使用 Chrome 的 `activeTab` 和 `scripting` 权限。用户点击扩展时，Chrome 会临时授予当前标签页访问能力；这些权限本身允许在当前标签运行脚本，因此应先审查源码再安装。当前实现通过双重域名检查，仅处理 `store.epicgames.com` 或 `www.epicgames.com` 的 HTTPS 页面；不申请 Cookie、持久站点或 Native Messaging 权限。

合成页面上已在独立 Chrome for Testing profile 中通过真实用户点击动作验证；也已在用户自行登录的真实 Epic 商品页验证固定状态显示。显示「无法确认」时不应视为登录失效。

## 手动测试

也可以在终端运行 `node scripts/prepare-epic-page-check.mjs`，生成只包含本实验文件的独立副本，并显示摘要和后续步骤。该脚本不安装扩展、不修改 Chrome 设置、不访问任何网站或账号；清单检查与摘要不代替源码审查。

1. 审查本目录的 `manifest.json`、`popup.html` 和 `popup.js`。
2. 如用户同意运行未上架的本地扩展，在自己的 Chrome 扩展管理页启用开发者模式，选择「加载已解压的扩展程序」，选择本目录。
3. 在日常浏览器中自行打开 Epic 官方页面、登录并完成安全验证；不要向他人提供密码、验证码或 Cookie。
4. 点击该扩展的图标，再点击「检查当前 Epic 页面」，只反馈弹窗中的固定状态。
5. 测试结束后，在扩展管理页移除此实验扩展；如测试前未开启开发者模式，可按个人偏好将其关闭。

此实验尚不能读取账户信息、连接 DSH 或自动领取，也不能保证后续自动化能通过 Epic 的安全检查。
