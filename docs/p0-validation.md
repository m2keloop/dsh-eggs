# 验证记录

日期：2026-11-20。当前为开发中的实验实现，不应接入真实账号。

## 已验证

- 基于 DSH `0.2.2-rc.5` 组件，以合成模型、合成会话及测试适配器验证完整链路：创建配置并登录、加密后重新打开本地存储、创建每日任务、使用 DSH 的手动执行接口触发同一任务、向 Agent 投递并调用 `egg_run`、模拟提交与到账核验、读取运行记录。测试替身负责提供模型和 Session 创建，未等待真实的 24 小时到期；任务投递后仍保持启用。另行启动隔离的官方 DSH Web Host，验证插件服务、工具及 `eggs-runner` preset 加载，preset 仅向模型暴露 `egg_run`。
- 创建本地配置、加密并重启后恢复合成凭据；AES-256-GCM 绑定实例和配置 ID。错误密钥、密文篡改、实例或配置不匹配均失败。系统凭据库缺少密钥时，只要当前实例存在任何密文，都不会重新生成替代密钥。
- DSH 自带系统锁绑定使两个进程不能同时持有本地数据写锁。内核锁可在进程终止后释放。提交前记录意图，超时或无法验证时记录未知结果，后续先验证再判断是否提交；同一机会的并发操作被串行化。
- 在隔离浏览器中用全合成网页测试商品按钮、结算 iframe 和金额处理。Epic 的公开目录接口及可见独立浏览器中的公开商品页实测可访问；无界面浏览器在此环境返回 403。
- 经用户同意，在独立可见浏览器尝试真实 Epic 登录时，Cloudflare 安全检查反复出现，未完成登录；本次未取得真实会话、未提交领取，测试临时目录已清理。无法仅凭该现象确定是哪一项检查触发。
- 用户在日常 Chrome 中主动登录并使用只读实验扩展，商品页显示已登录和可领取。进入领取流程后出现设备不受支持提示；结算框加载后显示商品为 `CN¥0.00`，点击领取须接受 Epic 最终用户许可协议等确认。经用户对该具体商品及条款明确同意后，人工操作浏览器点击领取；随后商品页显示 `In Library`。这验证了用户现有浏览器中的一次真实零元领取和商品页状态，不代表插件已经连接该账号，也没有验证权益 API。正式插件的下单路径目前无条件停止并提示人工处理。
- 检查浏览器无障碍树时，工具输出意外包含一段临时结算会话标识；该标识未写入项目文件，是否失效尚未核验。后续采集应先移除 URL 与敏感字段再输出，不能保存或转发原始结算页面信息。
- Cloudflare 官方说明生产验证不支持 Playwright 等自动化浏览器；这与本次验证循环相符，但不能证明具体触发原因。[Cloudflare 支持的浏览器](https://developers.cloudflare.com/cloudflare-challenges/reference/supported-browsers/)。后续需要用户自行完成站点验证，并评估适合站点规则的登录和领取途径，不能承诺现有 Playwright 路径能够使用真实账号。
- 隔离 DSH Web 页面已验证：显示福利目录、创建合成配置、提示未登录、创建原生每日任务。Host 端验证非所有者不能调用页面接口，非法额外参数被拒绝。未在普通用户的 DSH 配置中验证。
- 在隔离 DSH 页面中输入国家代码，经过 Host 只读查询 Epic 的真实公开目录并显示结果；该路径不使用账号。配置增删、最近执行结果展示和定时任务去重也已通过合成数据测试。
- 在全新临时 DSH Web profile 和独立测试浏览器中，完成首次引导后验证了福利页面创建配置、未登录提示、读取执行记录、创建原生定时任务和删除配置。此测试不使用真实账号或日常 DSH 数据。
- 在隔离 DSH Web Host 注入仅测试使用的合成福利，完成预设选项、创建配置、模拟登录、手动执行与模拟核验、查看记录、修改设置、创建原生每日任务及删除配置；Web Host 和数据目录均为临时环境，未连接真实平台。
- 合成适配器验证了无需登录的福利不读取或保存凭据；注册校验会拒绝缺少必需方法的适配器。运行队列支持等待时取消且不允许后续操作越过正在执行的领取。
- 合成领取器验证了非敏感预设选项的声明、校验、持久化、修改及传递；配置更新与同一福利的领取操作串行执行，未声明的字段或选项会被拒绝。账号及令牌不能放在普通选项中。
- 执行记录只保存在本机，每个配置最多保留最近 50 条状态、数量和时间；已有的最近一次记录可自动迁移。历史文件与最近一次快照分别写入，异常退出时两者可能暂时不一致，不作为远端到账的凭据。
- macOS 一次性临时钥匙串探针测试了随机密钥保存和恢复；测试不读取登录钥匙串。默认测试跳过该探针，需单独设置 `DSH_EGGS_P0_KEYCHAIN=1`。
- 使用生产 `KeyringKeyProvider` 在 macOS 系统钥匙串中创建随机测试条目，完成合成会话加密、重启恢复和条目删除。测试未读取既有账号；需单独设置 `DSH_EGGS_TEST_SYSTEM_KEYRING=1`。

## 未完成和限制

- 日常 Chrome 的只读状态已检查，但真实账号接口字段、地区、验证码、订单总额及领取后库存判断尚未完成验证；模拟页面通过不能证明真实领取可用。页面仅保留最近 50 次运行结果；任务可以在 DSH 原生任务页管理。
- 系统凭据库生产适配器已在 macOS 用临时合成数据端到端验证；Linux 和 Windows 未做完整平台验证。Windows 当前写锁直接拒绝运行。
- Playwright 的临时浏览器上下文不是受 `credentials.enc` 加密的完整浏览器 profile；非正常退出后临时文件的残留处理尚未验证。不要声称浏览器产生的所有文件都被加密。
- 应用级工具范围限制不隔离同进程插件或同一系统用户下的其他进程；本项目尚未经安全审计。DSH 可能有自身独立的日志、遥测和会话上传设置，尚未覆盖所有组合。
- Schedule 回执表示消息已投递，不表示模型已调用工具、领取成功或商品到账。Host 停止、模型不可用或工具未执行时不会领取。实测需要在真实用户环境再次核验。
- 全新环境的 `npm ci` 尚未验证：当前环境离线缓存不全，在线安装尝试未完成。需要在可访问依赖仓库的干净环境验证安装及运行。

## 复现

使用 Node.js 24.9.0 或更高版本：

```sh
npm ci
npm test
```

可选浏览器离线测试：

```sh
DSH_EGGS_TEST_BROWSER=/path/to/chromium node --test tests/epic-browser-real.test.js
```

可选 macOS 临时钥匙串测试：

```sh
DSH_EGGS_P0_KEYCHAIN=1 node --test tests/keychain-macos.test.js
```

可选 macOS 系统钥匙串集成测试（创建并删除独立随机测试条目）：

```sh
DSH_EGGS_TEST_SYSTEM_KEYRING=1 node --test tests/system-keyring-live.test.js
```

这些测试仅使用合成数据；不要用真实账号凭据运行测试。
